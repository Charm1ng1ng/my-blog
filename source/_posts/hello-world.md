## Hexo简介

Hexo是一个快速、简洁且高效的静态博客框架。Hexo使用Markdown解析文章，只需几秒时间即可生成静态网页。

## 快速开始

### 创建新文章

```bash
hexo new "My New Post"
```

### 启动本地服务器

```bash
hexo server
```

### 生成静态文件

```bash
hexo generate
```

### 部署到服务器

```bash
hexo deploy
```
