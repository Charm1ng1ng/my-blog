RK3566是一款高性能ARM Cortex-A55架构的处理器芯片，广泛应用于嵌入式Linux开发场景。

<!--more-->

## 芯片特性

- CPU: 4x Cortex-A55 @ 2.0GHz
- GPU: Mali-G52 2EE
- NPU: 0.8TOPS算力
- 内存: 支持LPDDR4/LPDDR4X
- 接口: PCIe 3.0, USB 3.0, SATA 3.0, MIPI-CSI/DSI

## U-Boot编译

### 配置与编译

```bash
git clone https://github.com/rockchip-linux/u-boot.git
cd u-boot
make rk3566_defconfig
make -j$(nproc)

# 打包成可启动镜像
./tools/mkimage -n rk3566 -T rksd -d ./spl/u-boot-spl.bin rk3566-sdcard.img
cat ./u-boot.bin >> rk3566-sdcard.img
```

### 启动参数

```bash
setenv bootargs "console=tty0 console=ttyS2,1500000 root=/dev/mmcblk1p2 rw rootwait"
setenv bootcmd "load mmc 1:2 0x00200000 boot/Image; load mmc 1:2 0x0a00000 boot/rk3566.dtb; bootz 0x00200000 - 0x0a00000"
saveenv
```

## 驱动开发

### 字符设备驱动

```c
#include <linux/module.h>
#include <linux/kernel.h>
#include <linux/init.h>
#include <linux/fs.h>
#include <linux/cdev.h>
#include <linux/device.h>

#define DEVICE_NAME "rk3566_led"
#define CLASS_NAME "led_class"

static int major;
static struct class *led_class;
static struct device *led_device;

static int led_open(struct inode *inode, struct file *file)
{
    printk(KERN_INFO "LED device opened\n");
    return 0;
}

static ssize_t led_write(struct file *file, const char __user *buf, 
                         size_t len, loff_t *offset)
{
    char cmd[10];
    if (copy_from_user(cmd, buf, len))
        return -EFAULT;
    
    printk(KERN_INFO "LED command: %s\n", cmd);
    return len;
}

static struct file_operations fops = {
    .owner = THIS_MODULE,
    .open = led_open,
    .write = led_write,
};

static int __init led_init(void)
{
    major = register_chrdev(0, DEVICE_NAME, &fops);
    led_class = class_create(CLASS_NAME);
    led_device = device_create(led_class, NULL, MKDEV(major, 0), NULL, DEVICE_NAME);
    printk(KERN_INFO "LED driver initialized\n");
    return 0;
}

static void __exit led_exit(void)
{
    device_destroy(led_class, MKDEV(major, 0));
    class_destroy(led_class);
    unregister_chrdev(major, DEVICE_NAME);
    printk(KERN_INFO "LED driver removed\n");
}

module_init(led_init);
module_exit(led_exit);
MODULE_LICENSE("GPL");
MODULE_AUTHOR("Charm1ng");
MODULE_DESCRIPTION("RK3566 LED Driver");
```

### Makefile

```makefile
obj-m += led_driver.o
KDIR := /path/to/linux-kernel
PWD := $(shell pwd)

all:
    $(MAKE) -C $(KDIR) M=$(PWD) modules

clean:
    $(MAKE) -C $(KDIR) M=$(PWD) clean
```

## 常见问题

1. **启动失败**: 检查bootargs中的串口配置和根分区路径
2. **驱动加载失败**: 确认内核版本与驱动匹配
3. **网络不工作**: 检查以太网PHY驱动是否编译进内核
